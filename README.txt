MelaRun — web sitesi

Vercel dağıtımı: bu klasördeki dosyaları GitHub deposuna yükleyip Vercel’de projeyi içe aktarın. Framework preset: Other; Build Command ve Output Directory boş bırakılabilir (kök klasör).

Özel alan adınızı Vercel > Settings > Domains bölümünden ekleyin. HTML dosyalarındaki melarun.com.tr adresini kendi alan adınızla değiştirin.
Yerelde çalıştırma: python -m http.server 8000
Supabase bağlantı ayarları supabase-config.js içindedir.
